Técnica usada

  • transform-style: preserve-3d para habilitar el contexto 3D
  • perspective en el contenedor para proyección en perspectiva
  • Cada cara posicionada con translateZ, rotateX/Y
  • Animación infinita rotando 360° en ambos ejes simultáneamente
