Border Color Animation

Click or focus on the input to see the animated gradient border appear and rotate continuously.

Técnica usada

  • Div .border-effect posicionado absolutamente detrás del input
  • Gradiente multicolor con background-size: 300% para animar posición
  • :focus-within en el contenedor activa la animación
  • Transición de opacity de 0 a 1 en el foco
