Card Hover Effect

Hover over any card. The hovered card scales up while siblings blur and scale down — using only the CSS :has() selector.

Técnica usada

  • :has() selector — detecta si algún hijo tiene :hover
  • .wrapper:has(.card:hover) .card:not(:hover) — afecta a hermanos no hover
  • filter: blur() y transform: scale(0.9) en hermanos
  • Cero JavaScript requerido — CSS puro
