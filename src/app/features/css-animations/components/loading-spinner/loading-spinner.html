Loading Spinner

Orbiting dots loading animation using staggered CSS animation delays on 5 identical elements.

Técnica usada

  • 5 divs con animation-delay escalonado (0s, 0.15s, 0.30s, 0.45s, 0.60s)
  • Cada punto: rotate(0deg) translateY(-200%) → rotate(360deg)
  • Combinación de rotación + traslación crea el efecto orbital
  • Duración de 1.25s en loop infinito
