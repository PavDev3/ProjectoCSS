Técnica usada

  • scroll-snap-type: x mandatory + scroll-snap-align: center
  • animation-timeline: view(x) activa la animación según visibilidad en scroll
  • scrollbar-width: none para ocultar la barra de scroll
  • Padding especial para centrar la primera y última carta: calc(50% - 140px)
