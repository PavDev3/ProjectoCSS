Skeleton Loading

Shimmer skeleton loading placeholders used to indicate content is being loaded.

Técnica usada

  • Fondo degradado usando linear-gradient con shimmer de izq. a der.
  • background-size: 200% 100% para el efecto de barrido
  • @keyframes shimmer mueve el background-position de 200% a -200%
  • Placeholders con dimensiones realistas según el contenido esperado
