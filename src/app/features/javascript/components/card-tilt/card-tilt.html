Técnica usada

  • mousemove event para calcular posición relativa del cursor
  • perspective(600px) rotateX() rotateY() para el efecto 3D
  • radial-gradient dinámico en el glow siguiendo al cursor
  • Angular ViewChildren + manipulación directa del DOM
