Técnica usada

  • CSS Custom Properties (variables) cambiadas por clase en el elemento
  • localStorage para persistir la preferencia entre sesiones
  • Angular Signal para reactividad sin necesidad de detectar cambios
  • Transición suave con transition: all 0.3s ease en todos los elementos
