Circular Progress Bar

Animated SVG circular progress bars using stroke-dasharray and stroke-dashoffset techniques.

@for (skill of skills(); track skill.label) {
{{ skill.value }}% {{ skill.label }}
}

Técnica usada

  • stroke-dasharray = circunferencia total del círculo (2πr)
  • stroke-dashoffset controla cuánto del trazo es visible
  • Animación CSS en stroke-dashoffset de circunferencia a valor final
  • rotate(-90deg) para que empiece desde arriba (12 en punto)
